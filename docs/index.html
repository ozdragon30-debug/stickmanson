Stick Arena: Reborn

Stick Arena was a browser-based multiplayer shooter created by XGenStudios. After Flash was discontinued, the official servers went offline and the game became unplayable without a Flash emulator and access to a private server.

This project is a modern, open-source HTML5 reimplementation of Stick Arena — built as a starting point for future online games, or simply for anyone who wants to relive the experience. All original maps, weapons, and sprites are preserved.

Play offline against bots right here in your browser, or download the server file and host your own game for multiple players to connect to.
