About

Stick Arena was a browser-based multiplayer shooter created by XGenStudios. After Flash was discontinued, the official servers went offline. This is an open-source HTML5 reimplementation with all original maps, weapons and sprites. Play offline against bots right here, or host your own server for multiplayer.
